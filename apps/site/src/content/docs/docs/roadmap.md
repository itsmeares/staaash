---
title: Roadmap
description: What is planned for Staaash next, and what already shipped.
---

Staaash stays small on purpose, so this list stays short. There are no dates. Something ships when it is ready and safe for your files.

Ideas and votes go in [GitHub Discussions](https://github.com/itsmeares/staaash/discussions). Each planned item links to its issue, where you can follow it.

## Next

- **Resume big uploads without reading them again.** A resumed upload skips the part already sent. [#616](https://github.com/itsmeares/staaash/issues/616)
- **Owners resolve storage changes that need review.** A button for the cases the [Storage Check](/docs/storage-check/) stops on. [#595](https://github.com/itsmeares/staaash/issues/595)
- **Scheduled backups to another drive.** The library and database copied together, on a timer. [#529](https://github.com/itsmeares/staaash/issues/529)
- **Shorter share links.** [#531](https://github.com/itsmeares/staaash/issues/531)
- **Large text files open without freezing the viewer.** [#505](https://github.com/itsmeares/staaash/issues/505)
- **Desktop app:** choose light or dark ([#600](https://github.com/itsmeares/staaash/issues/600)), and set how many files upload at once ([#601](https://github.com/itsmeares/staaash/issues/601)).

## Later

- **Phone app.** Until then, Staaash works in your phone's browser.

## Shipped

- **2.0**, in testing as a release candidate: the desktop app that syncs folders, a new design in light and dark, a server for Windows without Docker, and an optional HTTPS setup. [Release candidates](https://github.com/itsmeares/staaash/releases)
- **1.2**, October 2026: Docker images for ARM64 servers as well as AMD64. [v1.2.0](https://github.com/itsmeares/staaash/releases/tag/v1.2.0)
- **1.1**, September 2026: upload whole folders by drag and drop. [v1.1.0](https://github.com/itsmeares/staaash/releases/tag/v1.1.0)
- **1.0**, August 2026: the first stable release. Upload, preview, share, trash and resumable uploads. [v1.0.0](https://github.com/itsmeares/staaash/releases/tag/v1.0.0)
